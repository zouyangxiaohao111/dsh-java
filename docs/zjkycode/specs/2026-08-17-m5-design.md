# dsh-java:里程碑 5 设计 —— 配置驱动加载(cordis.yml 兼容,Java/Node 插件混排,热更新)

- 日期:2026-08-17
- 状态:已批准(用户审核通过,"排成M5 开始用workflow执行")
- 范围:Loader(cordis.yml 兼容)+ 所有可用 dsh 插件配置进 Java + 随时替换/组合/自动热更新验证

## 1. 背景与目标

M1-M4 + agent 融合完成(115 测试):核心全对齐、三宿主 resolver、NodeWorkerJsHost、真实 dsh agent 包经桥跑通。M5 加**配置驱动加载层**——让 Java harness 有 dsh 同款 profile 骨架:

- 读 **dsh 同款 `cordis.yml`** 格式,Java 插件与 Node 插件混排;
- 经 `PluginRuntimeResolver` 自动选宿主(① Java ClassLoader / ② GraalJS / ③ Node worker);
- **随时替换/组合**(改配置换插件,不重启);
- **自动热更新**(配置或插件文件变更 → 重载插件树)。

## 2. 架构

```
dev.dsh.cordis.loader(新包)
  ├─ PluginLoaderService    读 cordis.yml → 条目树 → 注册进 registry
  ├─ Entry / EntryTree      include/group 语义(子集)
  ├─ HostSelector           java:/node:/graaljs: 前缀或 PluginRuntimeResolver 自动检测
  └─ 热重载                 复用 M3 FileWatcher/reload/回滚,监听配置 + 插件文件
src/main/resources/cordis.yml   ← 项目 profile(声明插件集)
```

### 2.1 cordis.yml 格式(dsh 兼容 + Java 扩展)

```yaml
plugins:
  - name: echo
    path: node_modules/@koishijs/plugin-echo          # dsh 写法
  - name: session-stats
    path: packages/dsh-session-stats
  - name: counter
    source: java:dev.dsh.demo.CounterPlugin           # Java 插件扩展
  - name: greeter
    source: graaljs:./plugins/greeter                 # 显式 GraalJS
include:
  - ./base.yml                                        # include 子集
```
- `path` = dsh 兼容(JS 插件经桥);`source` 带 `java:`/`node:`/`graaljs:` 前缀(扩展)。
- 无前缀或 `path` → 经 PluginRuntimeResolver 自动检测宿主。

### 2.2 替换/组合语义

- 改配置里插件的 source/移除条目 → loader 重新求值 → 新增条目注册、移除条目 dispose(复用 M3 registry.delete + reload)。
- 组合:Java 插件与 dsh JS 插件并列,服务互操作(经 ctx,统一 registry)。

### 2.3 自动热更新

- 监听 `cordis.yml` 变更 → 重载条目树;
- 监听插件源文件变更 → 复用 M3(Java ClassLoader / JS 上下文重启 / Node worker 重启);
- 失败回滚(旧实现保留)。

## 3. 构建

- 加 `jackson-dataformat-yaml`(Jackson 已有,补 YAML)。

## 4. 验证(M5 验收)

1. 一份 cordis.yml 混排 Java + dsh JS 插件,全部加载进 registry;
2. 随时替换:改配置换一个插件(source 换掉)→ 旧 fiber dispose、新插件生效,不重启;
3. 组合:Java 插件 provide 服务 → dsh JS 插件 inject 并调用(经 ctx);
4. 自动热更新:改配置/改插件文件 → 插件树自动重载(含失败回滚)。

## 5. 风险与对策

| 风险 | 对策 |
|---|---|
| YAML 解析/格式差异 | Jackson YAML;与 dsh cordis.yml 字段对齐 |
| include/group 递归 | 子集(先 include,group 后),防循环 |
| 热重载与已有 registry 冲突 | 复用 M3 reload/回滚 |
| 大量 dsh 插件配置 | 分层配置,按组 |
